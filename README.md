# 🏹 صائد الحشرات الطائرة ثلاثي الأبعاد | 3D Flying Insect Catcher

لعبة ثلاثية الأبعاد تفاعلية برسومات واقعية جميلة ومتقدمة مبنية باستخدام **Three.js** و **WebGL**، تضعك في دور صياد ومستكشف سفاري ثلاثي الأبعاد يحمل شبكة صيد لصيد مختلف الحشرات الطائرة في بيئة طبيعية خصبة وغنية بالتفاصيل.

---

## 🌟 مميزات اللعبة (Features)

1. **رسومات واقعية متقدمة (Realistic 3D Graphics):**
   - إضاءة شمسية ديناميكية ومؤثرات ظلال سينمائية عالية الدقة (`PCFSoftShadowMap`).
   - تصحيح وتدرج لوني واقعي (`ACESFilmicToneMapping`).
   - بيئة طبيعية غنية: تضاريس متموجة، أشجار مورقة، صخور جبلية، أزهار برية ملونة، وبحيرة مائية متلألئة بانعكاسات فيزيائية.
   - ذرات غبار ولقاح تسبح في أشعة الشمس مع ضباب جوي واقعي.
   - إمكانية التبديل بين أوقات اليوم: **نهار مشمس ☀️** / **غروب ذهبي 🌅** / **ليل ساحر 🌙**.

2. **شخصية بشرية ثلاثية الأبعاد وحركات واقعية (3D Human Character):**
   - مجسم بشري متكامل بزي المستكشف (قبعة استكشاف، سترة سفاري بجيوب، حزام، بنطال كارجو، وحذاء رحلات).
   - شبكة صيد حشرات مجسمة ثلاثية الأبعاد (مقبض خشبي، طوق معدني، ونسيج شبكي شفاف).
   - تحريك هيكلي متناسق:
     - وقوف وتنفس طبيعي (Idle).
     - مشي وركض سريع (Walk & Sprint) مع حركة الأقدام والأذرع.
     - قفز (Jump).
     - حركة ضربة الشبكة للصيد (Dynamic Net Sweeping Strike) مع رصد تصادم فيزيائي دقيق للحشرات.

3. **حشرات طائرة بذكاء اصطناعي وفيزياء الرفرفة (Flying Insects AI):**
   - **فراشة الملك (Monarch Butterfly):** رفرفة أجنحة انسيابية وتجوال هادئ بين الأزهار.
   - **اليعسوب اللازوردي (Azure Dragonfly):** سرعة فائقة وأجنحة مزدوجة شفافة ومناورات خاطفة.
   - **الدبور الذهبي (Golden Hornet):** طيران متعرج وسرعة استجابة وهروب عند المباغتة.
   - **الخنفساء الزمردية (Emerald Beetle):** طيران طنان بارتفاع منخفض وغلاف زمردي لامع.
   - **اليراعة المشعة (Radiant Firefly):** تشع ضوءاً فسفورياً حقيقياً يضيء الطبيعة ليلاً.
   - ذكاء اصطناعي للهروب: عند الاقتراب بسرعة أو التلويح بالشبكة، تستشعر الحشرات الخطر وتهرب في اتجاه معاكس!

4. **واجهة مستخدم عصرية ورادار مصغر (HUD & Radar):**
   - رادار دائري حي ومصغر يعرض الحشرات الطائرة المحيطة ومواقعها وأنواعها.
   - عداد النقاط ومضاعف الصيد المتتالي (Combo Streak).
   - شريط طاقة الركض (Stamina).
   - **موسوعة الحشرات الحقلية (Field Guide Encyclopedia):** تعرض معلومات وتفاصيل كل نوع مع ندرته والنقاط التي يمنحها وعدد ما قمت بصيده.
   - مؤثرات صوتية ثلاثية الأبعاد مولدة برمجياً (Web Audio API) دون الحاجة لملفات صوت خارجية: طنين الحشرات ثلاثي الأبعاد، صوت احتكاك الشبكة في الهواء، خطوات الأقدام، وأصوات الاحتفال بالصيد.

## 📱 التحكم من خلال الجوال (Mobile Touch Controls)

اللعبة تدعم شاشات اللمس والهواتف الذكية بالكامل (iOS Safari & Android Chrome):
- **عصا التحكم الافتراضية (Virtual Joystick):** في أسفل يسار الشاشة للتحرك في أي اتجاه 360 درجة.
- **زر الصيد بالشبكة (🎯):** زر عريض مميز في أسفل يمين الشاشة لتنفيذ ضربة الصيد.
- **زر الركض السريع (⚡):** لتفعيل وإلغاء الركض السريع.
- **زر القفز (🦘):** للقفز والتقاط الحشرات المرتفعة.
- **تدوير زاوية الرؤية (Camera Drag):** اسحب إصبعك في أي مكان على الشاشة لتدوير الكاميرا حول الشخصية بحرية، مع دعم التقريب والتبعيد بإصبعين (Pinch to Zoom).

## 🎮 طريقة اللعب والتحكم على الكمبيوتر (Desktop Controls)

| المفتاح | الوظيفة |
| :--- | :--- |
| **تحريك الفأرة** | تدوير زاوية الكاميرا الحرة حول الشخصية (Third-Person Orbit) |
| **W / A / S / D** أو **الأسهم** | التحرك للأمام والخلف واليسار واليمين |
| **Shift** (مع الحركة) | الركض السريع (Sprint) |
| **المسافة (Space)** أو **زر الفأرة الأيسر** | ضربة الشبكة لاصطياد الحشرات الطائرة |
| **E** | القفز (Jump) |
| **عجلة الفأرة (Scroll)** | تقريب وتبعيد الكاميرا (Zoom In / Out) |

## 🚀 تشغيل اللعبة محلياً (Run Locally)

اللعبة مصممة بحيث تعمل مباشرة في أي متصفح حديث دون الحاجة لتثبيت أي برامج أو حزم إضافية:

### الطريقة 1 (تشغيل مباشر):
- قم بفتح ملف `index.html` مباشرة في متصفحك (Google Chrome, Edge, Firefox, Safari).

### الطريقة 2 (عبر خادم محلي باستخدام Python):
```bash
# داخل مجلد المشروع:
python -m http.server 8000
```
ثم افتح الرابط: `http://localhost:8000` في المتصفح.
